PocketBite — Interactive Food Discovery Web App
HTML · CSS · JavaScript · LocalStorage
Developed a visually engaging food discovery web application that helps users decide what to eat through interactive filters for budget, cravings, cuisine, dietary preferences, and spice level. Built a database of 300+ food options, a randomized “Surprise Me” recommendation feature, persistent favorites, and Swiggy/Zomato search links. Designed a responsive, animated UI with a custom olive-green aesthetic, interactive food cards, mood-based discovery, and smooth micro-interactions.
